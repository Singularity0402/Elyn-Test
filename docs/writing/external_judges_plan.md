# 외부 AI 블라인드 재심사 계획 (사전등록, 2026-10-30, 결과 보기 전)

`results_v1.md`의 한계 1("심사위원이 모두 Claude 계열")을 줄이려고, 다른 회사 AI 두 곳에 같은 블라인드 원고를 심사시킨다.

## 설계
- **원고와 안내:** `results_v1/`의 T1~T3 A·B 원고 6편을 쓴다. 안내는 `JUDGE_BRIEF.md` 그대로다.
  - X/Y 배정은 `blind_key.json` 그대로다. 노트 파일(`*_notes.md`)은 보내지 않는다.
- **심사위원:** OpenAI 1개, Google Gemini 1개다.
  - 실행 시점에 각 회사가 API로 제공하는 가장 강한 일반 모델을 쓴다. 정확한 모델 ID를 결과 파일에 남긴다.
- **실행:** 심사위원마다 한 번만 돌린다(L8).
  - API 오류로 답이 없을 때만 같은 프롬프트로 다시 보내고, 그 사실을 기록한다.
  - 답이 JSON 형식을 어겨도 다시 묻지 않는다. 읽을 수 있는 범위에서 pick만 읽고, 못 읽으면 무효표다.
- **스크립트:** `run_external_judges.py`. API 키는 사용자 터미널의 환경변수로만 넣고, 파일·저장소에 남기지 않는다.

## 판정 (결과 보기 전에 정함)
- **외부 6표**(과제 3 × 심사 2) 가운데 B(매뉴얼)가:
  - **5표 이상:** "다른 회사 AI 심사에서도 매뉴얼 쪽 우세" → 기존 '확인'을 유지한다.
  - **2표 이하:** "외부 심사에서 반증" → 기존 '확인'은 Claude 계열 취향일 수 있다. 매뉴얼 v2에서 다시 검증한다.
  - **3~4표:** "불명" → 기존 판정에 '외부 미재현' 단서를 붙인다.
- **합산 15표(기존 9 + 외부 6) 참고값:** B 11표 이상이면 동전 던지기로 나올 확률은 약 6%다. 판정은 위 외부 6표 규칙으로만 한다.

## 검수 (다른 AI 결과는 따로 확인한다)
1. JSON의 점수 개수(5개)와 pick 값(X/Y)이 맞는지 본다.
2. 근거('why')가 원고에 실제로 있는 장면·문장을 가리키는지 원고와 대조한다. 없는 장면을 지어냈으면 그 표는 무효다.
3. 무효표는 판정에서 빼고, 남은 표로 같은 비율 규칙을 적용한다(예: 5표면 B 4표 이상 = 우세, 1표 이하 = 반증).
