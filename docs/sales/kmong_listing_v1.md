**등록 화면 규정**

- 주의 키워드는 입력 중 하이라이트된다(공지 kmong.com/support/expert-center/posts/580). 하이라이트된 말은 바꾼다.

## 0. 올리기 전에

- **[ ] 샘플 6~8곡을 준비한다.**
  - 장르 3종 이상, 30~60초 하이라이트로 만든다.
  - 루프 샘플 1개를 포함한다. 처음과 끝이 이어지는 걸 들려 주는 영상이 좋다.
  - 포트폴리오 탭에 올린다.
- **[ ] 설명문에 외부 링크·전화번호·메신저 ID를 넣지 않는다.** 크몽 밖 거래로 유도하면 제재 대상이다.
  - 직접 영업(유튜버·인디게임)은 크몽 고객이 아닌 사람에게만 따로 한다.
- **[ ] 사업자등록은 서두르지 않는다.**
  - 등록하면 "개인·사업자등록 없음"을 요구하는 공모전 일반부문에 못 나갈 수 있다(HANDOFF 4-4).
  - 반복 판매로 통신판매업 신고가 필요해지는 시점은 크몽 안내(posts/673)로 확인한다.
- **[ ] 음악 카테고리의 수수료는 수익금 계산기로 확인한다.** 실수령 약 78%는 추정이다.
- **[ ] 아래 []는 사용자 실제 정보로 바꾼다.** 쓰는 가상악기, 장르 강점, 응답 가능 시간이다.

## 1. 제목 후보 (30자 안팎)

1. **게임·영상 맞춤 BGM, 루프 구간까지 맞춰 드립니다** ← 추천
   - '루프'는 게임 개발자가 실제로 검색하는 말이다. 경쟁 페이지 표본에서 앞세운 곳이 적다.
2. 사람이 편곡·믹싱하는 AI 보조 맞춤 BGM
3. 인디게임 전투·필드·마을 BGM 루프 음원 제작

## 2. 검색 키워드 (크몽 AI 추천 목록에서 고른다)

게임BGM, 배경음악, 인디게임음악, 루프음악, 유튜브BGM, 오케스트라BGM, 판타지음악, 방송BGM

## 3. 서비스 설명 본문

```
게임·영상에 바로 넣을 수 있는 맞춤 배경음악을 만듭니다.
처음과 끝이 자연스럽게 이어지는 루프 구간까지 맞춰 드려서, 게임 엔진이나 편집 프로그램에 그대로 반복 재생하실 수 있습니다.

■ 이런 분께 맞습니다
- 인디게임의 마을·필드·전투·보스 테마가 필요하신 분
- 유튜브·방송 오프닝, 브이로그, 쇼츠에 쓸 나만의 BGM이 필요하신 분
- 무료 음원이 다른 채널과 겹쳐서 고민이신 분

■ 작업 방식 (투명하게 알려 드립니다)
AI로 만든 MIDI 아이디어를 바탕으로, 제작자가 직접 가상악기를 고르고 편곡·믹싱·마스터링해 완성하는 'AI 보조 음악'입니다.
AI 생성 파일을 그대로 넘기지 않습니다. 사람이 악기 배치, 구성, 소리 균형을 하나하나 다듬습니다.
주력 스타일: [예: 판타지 오케스트라, 액션 전투곡, 잔잔한 피아노]

■ 받으시는 것
- WAV(44.1kHz/24bit 이상)와 MP3
- 루프 구간 표시(시작·끝 지점) 또는 인트로/루프/엔딩 분할 파일(옵션)
- 이용허락 범위를 적은 확인서(PDF)

■ 작업 순서
1. 문의: 용도, 분위기, 참고곡(최대 3곡), 길이, 마감일을 알려 주세요.
2. 방향 확인: 악기 구성과 템포를 정리해 확인받습니다. (작업 시작 전 합의)
3. 데모: 30~60초 데모를 먼저 들려 드립니다.
4. 완성: 피드백을 반영해 전체 길이로 완성하고 납품합니다.
5. 수정: 패키지별 횟수 안에서 템포·악기·구성을 수정합니다.

■ 의뢰 시 보내 주시면 좋은 것
- 사용처(게임 장면, 영상 종류)와 화면·영상 자료(있다면)
- "이런 느낌" 참고곡과, 그 곡에서 좋은 부분(악기, 속도, 분위기)
- 꼭 피하고 싶은 소리

■ 수정 범위
수정은 템포, 악기 교체, 구간 길이, 소리 균형 조정을 말합니다.
처음 합의한 장르·분위기를 완전히 바꾸는 요청은 새 작업으로 안내드립니다.

■ 이용 범위와 고지
- STANDARD는 비독점 상업 이용허락, DELUXE·PREMIUM은 독점 이용허락입니다.
  (독점: 같은 곡을 다른 분께 다시 판매하지 않습니다.)
- 사용 가능: 게임, 유튜브·방송, SNS, 광고, 발표 영상 등 의뢰하신 프로젝트. 기간·지역 제한 없음.
- 사용 불가: 음원만 따로 재판매·배포, 음원 사이트 단독 발매, 음원·스템을 샘플·루프 소재로 재배포.
- 음저협 등 신탁단체 등록과 유튜브 Content ID 등록은 해당 기관 심사에 따르며 보증하지 않습니다. 필요하시면 작업 전에 말씀해 주세요.
- 제작자는 완성곡을 포트폴리오에 소개할 수 있습니다. 원하지 않으시면 미리 알려 주세요.
- 저작재산권 양도는 법이 허용하는 범위에서 옵션으로 제공합니다.
```

## 4. 패키지 (런칭가 = 첫 2주·첫 5건 한정)

| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 패키지 제목 | 짧은 루프 BGM | 독점 메인 테마 | 테마 + 변주 세트 |
| 설명(한 줄) | 60초 이내 루프 1곡, 쇼츠·인트로·작은 장면용 | 180초 이내 1곡, 게임 메인 테마·영상 대표곡 | 180초 메인 + 변주 2종(예: 평화/전투) + 스템 |
| 길이 | 60초 | 180초 | 180초 + 변주 2종 |
| 권리 | 비독점 이용허락 | 독점 이용허락 | 독점 이용허락 + 스템 |
| 루프 구간 맞춤 | 포함 | 포함 | 포함 |
| 수정 | 2회 | 3회 | 3회 |
| 작업일 | 3일 | 4일 | 5일 |
| **런칭가** | **19,000원** | **49,000원** | **99,000원** |
| 리뷰 5건 후 | 29,000 | 69,000 | 129,000 |
| 리뷰 10건 후 | 39,000 | 89,000 | 169,000 |

- 3단이 같은 '루프 맞춤'을 포함하고, 길이와 권리로 나눈다. 리뷰 많은 상위 판매자의 구조다(249491).
- PREMIUM은 DELUXE를 돋보이게 하는 기준점 역할도 한다.

## 6. 자주 묻는 질문

```
Q. AI로 만든 음악인가요?
A. AI가 만든 MIDI 아이디어에서 시작하고, 악기 선택·편곡·믹싱·마스터링은 사람이 합니다. 결과물은 사람이 끝까지 다듬은 음원입니다.

Q. 유튜브에서 저작권 문제가 생기지 않나요?
A. 제작자는 이 음원을 Content ID에 등록하지 않습니다. 그래도 혹시 저작권 주장이 걸리면 이용허락 확인서와 작업 파일로 이의 제기를 도와 드립니다.

Q. 수정은 어디까지 되나요?
A. 템포, 악기 교체, 길이, 소리 균형은 패키지 횟수 안에서 고칩니다. 장르를 완전히 바꾸는 것은 새 작업입니다.

Q. 게임 엔진에서 끊김 없이 반복되나요?
A. 루프 시작·끝 지점을 맞춰 드리고, 원하시면 인트로/루프/엔딩 분할 파일을 드립니다.

Q. 상업 게임(유료 판매)에도 쓸 수 있나요?
A. 네. 의뢰하신 프로젝트 안에서는 유료 게임·광고에도 쓰실 수 있습니다.
```
- 두 번째 답은 "주장이 안 걸린다"고 보증하지 않는다. 가상악기 루프·샘플이 다른 등록 음원과 겹치면 걸릴 수 있다.
- 쓴 가상악기·샘플 라이브러리의 라이선스가 "완성곡 상업 이용 허용"인지 한 번 더 확인한다(money_paths 6절: Spitfire·NI는 허용, 샘플 단독 재배포 금지).

## 7. 응답 템플릿 (응답 속도가 노출 순위에 들어간다)

**첫 문의**
```
문의 감사합니다! 바로 방향을 잡을 수 있게 세 가지만 알려 주세요.
1) 어디에 쓰시나요? (게임 장면 / 영상 종류)
2) 참고곡 1~3곡과 그 곡에서 좋은 부분
3) 필요한 길이와 마감일
받는 대로 악기 구성과 템포를 정리해 드리고, 맞는 패키지를 추천드릴게요.
```

**방향 확인**
```
정리해 보면 [분위기] 느낌에 [악기 2~3개] 중심, 템포 [BPM], 길이 [초]입니다.
루프는 [구간]이 이어지게 맞추겠습니다. 이대로 진행할까요?
데모는 [날짜]까지 30~60초로 먼저 보내 드립니다.
```

**납품**
```
완성본 보내 드립니다.
- WAV / MP3 각 1개, 루프 구간: [mm:ss ~ mm:ss]
- 이용허락 확인서(PDF) 첨부
남은 수정 [N]회 안에서 템포·악기·길이 조정 가능하니 편하게 말씀해 주세요.
마음에 드셨다면 구매 확정과 솔직한 후기를 부탁드립니다.
```
- 후기를 대가(할인·사은품)로 부탁하지 않는다. 크몽 정책 위반 가능성이 있다(sales_strategy 4절, 미확인).

## 8. 썸네일 문구

- 큰 글씨: **"루프까지 맞춘 맞춤 BGM"**
- 작은 글씨: "게임 · 유튜브 · 방송 | 사람이 편곡·믹싱"
- 배경: 파형 + 게임 화면 느낌의 어두운 판타지 톤. 남의 게임 화면·캐릭터는 쓰지 않는다.
- 이미지를 AI로 만들면 상업 이용 가능한 도구로 만든다.
