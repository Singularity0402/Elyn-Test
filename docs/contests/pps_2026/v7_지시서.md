# v7 수정 지시서 (2026-10-30, 메인 세션 판정)

**목표:** 이영도 『눈물을 마시는 새』 평가 수준의 개연성을 갖추는 것이다. "읽다가 '운이 좋았네' 싶은 곳이 있어도 끝까지 읽으면 전부 설명된다."

**입력:** `감사_개연성_v6.md`, `감사_정합_v6.md`, `감사_문장_v6.md`(세 감사는 서로 독립적이다)와 `원고_v6.txt`.

## 1. 바꾸지 않는 것

- 전제, 반전(석주의 청력), 결말(보청기 · '2050 입고' 꼬리표), 첫 장면과 마지막 장면의 꼬리표 짝.
- 인물 4명의 이름과 말투의 바탕(석주 충청, 진아 대구).
- "내 이름으로 풀기 전엔 안 풀려"(S#6)와 "내 이름으로 철회한다"(S#19)의 짝.
- **"땜납이 되면요. 대신 기판에 붙죠."의 뜻.** 주석이 보청기 기판이 된다는 주제 문장이다. 문장 감사의 삭제안은 기각한다. 표현은 다듬어도 된다.
- NF-51: 기관 찬양 문장, 홍보용 숫자 화면, '기본계획 개정' 같은 알림은 넣지 않는다.
- 실존 기업·국가·부처명, 유명 문구는 쓰지 않는다.
- 분량: 양식 기준 21~26쪽. 지금은 약 22.2쪽이다. 늘어나는 것은 10% 이내로 한다.

## 3. 일하는 방식

1. 세 감사 파일을 끝까지 읽는다. 각 감사의 모든 항목(개연성 A의 미설명 10·부분 20, 정합 A~E 44건, 문장 A~F)에 대해 판정한다: **반영 / 변형 / 기각(이유) / 해당 없음(중복)**.
2. `원고_v7.txt`를 만든다.
3. **반영 장부** `v7_반영장부.md`를 만든다. 감사 항목 ID마다 판정과 바꾼 위치를 적는다. 기각은 이유 한 줄. 이 장부가 다음 재감사의 대조표가 된다.
4. 회귀 점검을 한다.
   - 쪽 수, 탭, 192자 이하 지문, 씬 번호 연속, 조달청 2회
   - 같은 인물 연속 대사 0
   - 모든 날짜·요일·시각을 다시 계산한다
5. 줄거리가 바뀌면 `신청서_문구.md`의 로그라인·시놉시스·등장인물을 맞춘다. 시놉시스는 1,100자 이하로 한다.
6. 커밋하지 않는다.
