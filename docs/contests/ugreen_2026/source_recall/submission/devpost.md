# Devpost 입력 문구

**Project name**

Source Recall

**Tagline**

Trace a withdrawn source through studio mixes to the exports still on your NAS.

**Description**

One voice recording can end up in several edits, mixes, and exports with different names. Source Recall traces the dependency chains recorded by a producer and checks the selected UGREEN AI NAS delivery folder. The report shows which affected exports are present, which are absent from the checked folder, and which entries require review. It also shows untracked entries so a producer can reconcile the delivery folder before release.

The initial Skill uses the Uliya filesystem expert and two Markdown files. The official static checker passed. The local reference implementation was exercised with synthetic examples. Validation of installation and runtime behavior on the assigned UGREEN AI NAS is pending.
