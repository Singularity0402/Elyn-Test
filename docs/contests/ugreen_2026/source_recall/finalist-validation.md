# 결선 장비 검증

주최사 이메일로 지정된 하루에만 장비를 사용할 수 있다. 그 전에 `demo/lineage.txt`, `demo/exports/`, 1차 ZIP과 화면 녹화 도구를 준비한다. 테스트는 참가자에게 배정된 장비·계정과 합성 자료로 진행한다.

| 순서 | 확인할 결과 | 통과 기준 |
|---|---|---|
| 설치·호출 | Uliya에서 소스 ID와 두 범위를 지정해 실행 | 등록된 파일 전문가만 호출하고 해당 맵과 디렉터리를 정확히 식별 |
| 정상 추적 | 트레일러가 존재하고 서로 다른 믹스 두 개가 같은 파일에 기여 | 트레일러 Hold 1행, 경로 2개. 배경 음원은 선택 원본의 경로 없음 |
| 혼합 상태 | 대소문자 불일치, 누락, 추적되지 않은 메모 | 오디오 Review, 소셜용 파일 Absent, 메모는 Untracked |
| 범위 공격 | 맵의 파일명에 상위 경로 또는 추가 명령 삽입 | 결과에 원문 명령을 재생하지 않고 폴더 목록 조회 전에 중단 |
| 권한·불완전 | 폴더 열람 거부, 숨김 항목 포함 여부, 65개 항목, 링크 | 범위를 넓히지 않고 증거가 불완전하면 존재·부재 확정 중단. 링크를 따라가지 않음 |
| 반복·중단 | 같은 입력 재실행 및 중간 취소 | 동일 증거에서 동일 결과. 취소된 조회의 증거를 새 실행에 재사용하지 않음 |

첫 장비 테스트에서 실제 읽기 결과와 목록 범위·종류가 필요한 증거를 제공하는지 확인한다. 필드 이름은 도구가 반환한 실물을 기준으로 기록한다. 증거가 없는 상태에서 추정으로 통과를 만들지 않는다. 수정 후 같은 시나리오를 다시 돌린다.

## 시연 녹화 순서

1. 15초. 편집자가 교체할 원본과 두 경로를 소개한다.
2. 60초. 맵과 폴더를 지정하고 Uliya에서 실제로 실행한다. 트레일러 한 건에 경로가 두 개 붙는 결과를 보여준다.
3. 35초. 누락, 대소문자 불일치, 별도 검토할 파일을 설명한다.
4. 20초. 잘못된 맵을 넣어 추가 접근 없이 멈추는 흐름을 보여준다.
5. 15초. 보고서가 다루는 범위를 설명한다.

영상에서 로그인 정보, 임시 접속 URL, 실제 개인 자료를 가린다. 결선 제출에는 실제 장비 실행 영상과 영어 내레이션을 사용한다. 종료 전에 수정한 패키지와 원본 녹화를 확보하고, 이후 3분 이내 공개 유튜브 영상과 최종 ZIP을 전용 Devpost 링크에 제출한다. 결선 마감은 한국 시간 **2026-12-01 16:45**. [공식 결선 규정](https://ugreenhackathon.devpost.com/rules)
