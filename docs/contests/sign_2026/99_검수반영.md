# 99. 심사위원장 검수 반영 내역 (2026-11-05)

- 검수 결과는 fatal 5건, major 9건, minor 5건, why_not_first 4건이었다. 아래는 건별로 "무엇을 어떻게 고쳤는지" 또는 "왜 못 고쳤는지"를 적은 것이다.
- 이번 작업에서 실제로 한 확인: 04 SVG를 Chrome으로 렌더링해 글자·점선을 눈으로 확인했고, 05 도면은 Chrome으로 PDF 출력해 정확히 1쪽임을 확인했다. 도안 PNG 2장은 코드로 만들어 눈으로 확인했다. 이미지 AI(ChatGPT, Gemini)는 이 환경에서 실행하지 못했으므로 프롬프트의 실제 동작은 검증하지 못했다.
- 시도했으나 실패한 확인: law.go.kr 시행령 제4조 본문(조문 페이지가 로드되지 않음), 국가법령 공개 API(사용자 인증 요구), OpenAI 이용약관(HTTP 403), Google 생성형 AI 약관 페이지(출력물 권리·상업 이용에 대한 내용이 없고 다른 약관을 가리킴). 공식 홈페이지 info.asp는 열려서 도면 1장, 주·야간 시뮬레이션 1장, 300dpi PDF, 마감 시각·용량·페이지 수 제한 없음을 다시 확인했다.
