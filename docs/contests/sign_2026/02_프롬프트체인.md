# 02. 프롬프트 체인 (11단계)

- 목적: 공모 심사 항목 "AI 활용도(단계별 프롬프트의 정교함, 프롬프트와 결과물 간 논리성)"를 증명한다. 각 단계의 출력이 다음 단계의 입력 근거가 되도록 연결했다.
- 사용 도구: ChatGPT(텍스트·이미지 생성), Gemini(이미지 분석·채점·점검), ComfyUI(업스케일), Photopea(합성). 한글 상호는 이미지 AI에 맡기지 않고 벡터(04)로 합성한다.
- 결과는 아직 없다. "기대 결과"는 합격 기준이며 실제 결과가 아니다. 각 단계의 실행 기록 칸은 응모자가 직접 채운다. 모든 프롬프트 원문, 생성 이미지, 날짜는 삭제하지 않고 보관한다(후보작 영상 검증에 쓰인다).
- 이전 판과 달라진 점: ① 04 SVG와 05 도면도 체인의 단계(9, 10)로 넣어 녹화 화면에서 만들 수 있게 했다. ② Gemini 단계를 "거리를 읽는다"가 아니라 "생성 결과가 사양을 지켰는지 블라인드로 검증한다"로 바꿨다(자기 입력을 되읽는 순환 논리 제거). ③ After 주간·야간을 AI 편집으로 만들지 않고 Before 사진에 벡터 합성한다. ④ 탈락안 2장은 "의도적 대조군"으로 성격을 바로잡고, 선택은 컨셉 A·B·C를 미리 고정한 기준으로 채점해서 한다.

## 사용 규칙

1. 한 단계마다 새 대화를 시작하지 말고, 이미지 단계(3, 4, 7, 8)는 같은 대화 안에서 이어서 만든다. 새 생성이므로 기준 이미지를 첨부한다.
2. 프롬프트는 먼저 읽는다. 바꿀 부분이 있으면 바꾸고 수정 전후 문장을 기록 칸에 남긴다(논리성의 증거). 바꾸지 않았으면 "원문 그대로"라고 쓴다.
3. 결과가 나올 때마다 화면 녹화를 켠 상태에서 진행한다. 계정 이메일과 이름이 화면에 보이지 않게 별도 브라우저 프로필을 쓴다.
4. 법령 판단은 AI에게 맡기지 않는다. 단계 1의 입력은 01 문서의 정리표뿐이고, AI가 조항을 만들어 내면 그 출력은 탈락이다. 정리표는 원문 대조 전 자료라는 점을 프롬프트에도 적었다.
5. 파일명은 img_단계번호_내용.png. 합성 후 final_day.png, final_night.png.
6. 이 문서에 "사람의 작업"이라고 쓴 단계는 AI가 한 것처럼 쓰지 않는다. 신청서와 영상 모두 같은 구분을 따른다.

- **응모자 작업(AI가 아님)**: 01 문서 1절의 조항을 law.go.kr 원문과 대조하고 07 문서 5절의 체크표에 일치/불일치를 기록한다. 이 대조를 마치기 전에는 신청서에 "원문 확인"이라고 쓰지 않는다.

```text
- 실현가능성(25): 법규 시각 단서(광원 노출, 형광색, 점멸 표현, 과도한 돌출, 창 가림)와 시공 가능성. 법규 단서가 보이면 -10, 확인 불가는 감점하지 않고 "확인 필요"로 쓴다.
```

```text
2. 간판 외 글자·로고: 이웃 간판, 입간판, 박스, 창, 하늘에 글자·숫자·로고·워터마크가 있는가(있으면 FAIL, 위치를 쓴다).
3. 낮밤 일관성: 주간과 야간에서 건물 윤곽, 창, 배수관, 이웃 간판 위치가 서로 맞는가.
4. 높이선: 새 판 윗변이 건물 수평 띠의 아랫선에 붙어 있는가. 어긋나면 대략 몇 px(또는 몇 mm)인가.
5. 법규 시각 단서: 광원이 직접 보이는가, 형광색이 있는가, 점멸 표현이 있는가. 있으면 FAIL.
6. 야간 후광: 후광이 글자 가장자리에서 절제되는가, 번짐이 과하거나 네온처럼 보이는가. 이웃 간판 빛과 광원 방향·색온도가 일관되는가.
7. 합성 티: 새 판의 그림자·경계·원근이 사진과 어울리는가. 어색한 곳을 위치와 함께 쓴다(예: 판 아래 그림자가 없음).
8. 사람 얼굴, 자동차 번호판, 개인 식별 정보가 있는가.
FAIL이 하나라도 있으면 마지막에 "수정 우선순위"를 3개 이하로 쓴다.
```

### 기대 결과 (합격 기준)

- 03 문서 8-2의 정렬 기준과 8-3의 6항목 점검 결과가 기록되어 있다.
- Gemini 점검 8항목에 FAIL이 없다. FAIL이 있으면 수정 후 같은 프롬프트로 재점검한다. "판독 불가"는 응모자가 200%로 확대해 직접 확인하고 결과를 쓴다.
- 판 글자와 점선은 클로즈업에서 읽힌다. 확대해도 판이 번지지 않는다(벡터 합성).
- 신청서의 합성 설명이 "AI가 만든 After"가 아니라 "AI가 만든 Before 사진에 응모자가 벡터 판을 합성"이라고 정확히 쓰여 있다.
