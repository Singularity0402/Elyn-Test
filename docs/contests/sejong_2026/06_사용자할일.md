## 합성 (11/11~11/13, 약 2~3시간)

```powershell
# 1) 구역 점검용(빨간 구역선과 '점검본 제출금지' 표시, 폴더 출력_점검, 제출 금지)
python -I 04_합성.py --images 컷이미지 --show-zones

# 2) 제출본: 8장이 모두 있어야만 만들어짐. 폴더 출력_제출, 파일명 AI 컷툰_서울에 졌습니다_이름_NN.jpg
python -I 04_합성.py --images 컷이미지 --name 이름 --sheet
```

- [ ] 점검본에서 말풍선이 호랑이 얼굴이나 중요한 사물을 가리지 않는지 본다. 가리면 07 의 해당 컷 좌표(`E(...)`의 상자)를 옮기거나 이미지를 재생성한 뒤 07 을 다시 실행한다.
- [ ] 원본이 약 1024px 폭이라 1440 폭으로 확대된다. 화질이 아쉬우면 사용하는 업스케일 도구로 컷 원본을 먼저 키운 뒤 `컷이미지` 에 다시 넣는다. 수상 시 요청받을 수 있는 원본은 업스케일 전 파일이므로 둘 다 보관한다.
- [ ] 제출본 8장이 1440x1800, JPG이고 합계 용량이 문의 회신의 제한 이내인지 04의 '제출본 검증' 출력으로 확인한다. 초과하면 `--width 1080` 또는 `--quality 90`.
- [ ] 미리보기(`출력_제출_미리보기`, 제출 파일 아님)로 8장의 흐름(컷 1과 8의 구도 일치, 캔 색, 호랑이 일관성)을 본다.
- [ ] 문의 회신이 압축 파일을 요구하면 `--zip` (결과는 `출력_제출_zip`). 이미 만든 `출력_제출` 이 있으면 폴더를 비우거나 `--overwrite` 를 쓴다.
- [ ] 제출 파일은 `출력_제출` 폴더의 것만 쓴다. 점검본(`점검_` 접두), 시험본(`시험_`, SAMPLE 표시), 원본(`원본_`)은 파일명과 표시로 구분된다.
