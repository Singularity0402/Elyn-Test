# 02. 캐릭터시트 지시문 (ChatGPT 이미지용)

이 문서는 `07_지시문_가이드_생성.py` 가 자동 생성한다(직접 고치지 않는다).

목적: 8컷 내내 같은 호랑이, 같은 후드 시민, 같은 승강장이 나오게 '기준 이미지' 3장을 먼저 만든다. 글자는 시트에도 넣지 않는다(이름표 금지).

## 작업 순서

1. 시트 A -> B -> C 순서로 각각 새 대화 또는 같은 대화에서 생성한다. 시트 C는 `구도가이드/가이드_시트C.png` 를 첨부한다.
2. 각 시트의 체크리스트를 통과할 때까지 재생성한다. 통과본을 `시트A_호랑이.png`, `시트B_후드시민.png`, `시트C_빈승강장.png` 로 저장한다.
3. 호랑이 닮음 판정은 00_계획.md 5절의 절차를 따르고 결과를 `판정기록.txt` 에 남긴다. 닮음이 해소되지 않으면 그 시트는 쓰지 않는다.
