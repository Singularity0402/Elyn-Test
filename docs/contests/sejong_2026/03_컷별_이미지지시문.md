# 03. 컷별 이미지 지시문 (ChatGPT 이미지용, 한글은 04_합성.py 가 따로 합성)

이 문서는 `07_지시문_가이드_생성.py` 가 자동 생성한다. 직접 고치지 말고 07의 데이터를 고치고 다시 실행한다(문서 간 숫자 불일치 방지).

## 사용 순서

1. 02의 시트 A·B·C 를 만들어 통과본을 저장한다.
2. 컷마다 **새 대화**를 연다. 일관성의 근거는 대화 기록이 아니라 첨부 이미지(시트 3장, 구도 가이드, 직전 컷)다. 대화가 길어지거나 같은 오류가 3번 나오면 새 대화로 시트부터 다시 시작한다.
3. 컷별 '첨부 이미지'를 모두 붙이고 코드 블록 전체를 한 번에 붙여 넣는다(`지시문/컷NN.txt` 와 같은 내용).
4. 결과를 '확인 항목'으로 점검한다. 틀린 부분은 '자주 틀리는 부분'의 수정 문장으로 고쳐 달라고 요청한다(전체를 다시 쓰지 말고 그 문장만).
5. 통과본을 `컷이미지/컷01.png` 처럼 저장한다(파일명 첫 숫자가 컷 번호).

## 지시문 설계 원칙

- 위치·크기는 구도 가이드 이미지가 담당하고, 글은 핵심 사물만 % 로 적는다. 좌표 20개를 글로 지키게 하지 않는다.
- 가이드 이미지는 위치·크기·시점만 알려 주는 러프이며 그림체는 따르지 말라고 지시문에 적었다. 가이드의 도형을 그대로 베끼면 '가이드 그림체를 따르지 말라'고 다시 요청한다.
- 이미지 AI가 구역을 비우지 못해도 04의 `--backing` 이 말풍선 뒤에 단색 판을 깔아 가독성을 지킨다(재생성 없이 쓸 수 있는 안전장치).
- ChatGPT가 4:5를 직접 지원하는지는 확인하지 못했다. 2:3을 기본으로 하고 04가 위아래 각 8.3%를 자른다.
- 생성 횟수 한도는 요금제에 따라 다르다(확인 필요). 컷당 3회 이내 통과를 목표로 24~30장을 예산으로 잡고, 한도에 걸리면 다음 날 이어서 한다. 새 대화에서도 첨부만 같으면 일관성은 유지된다.
- 승강장 컷(1·8)이 가장 어렵다. 컷 1을 먼저 확정한 뒤 컷 8은 컷 1을 첨부해 '편집하듯' 만든다. 권장 순서: 컷 1 -> 8 -> 2 -> 5 -> 3 -> 4 -> 6 -> 7.
