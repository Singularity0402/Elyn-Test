# 00. 계획: 세종사이버대 K-빌런 공모전 컷툰 「서울에 졌습니다」

최초 작성 2026-11-05(목), 심사위원장 검수 결과를 반영해 같은 날 개정. 근거 자료: `docs/contests/공모전_조사결과_2026-11.json`(세종 항목), `docs/contests/종합계획_2026-11.md`, 그리고 개정 시 공식 공고 페이지(cms.sjcu.ac.kr/ai-intel/community/data.do?mode=view&articleNo=138855)를 다시 열어 대조한 내용. 공고 첨부 지원서(.hwp)는 내려받지 않아 열람하지 못했다.

## 0. 현재 상태를 솔직히

- 이 폴더에는 **완성 이미지가 0장**이다. 이미지 생성은 사용자가 ChatGPT로 해야 하며 Claude는 이를 대신하지 못한다. 지금 있는 것은 이야기, 이미지 지시문, 컷별 구도 가이드 이미지 8장, 한글 합성기, 지원서 문안이다.
- 구도 가이드(`구도가이드/가이드_컷NN.png`)는 위치·크기·시점만 잡은 러프 블록이며 작품이 아니다. ChatGPT에 첨부해 지시문의 숫자를 대신하는 도구다.
- 합성기는 가이드 이미지를 컷 이미지로 쓴 시험 실행에서 8장, 6컷, 점검본, 시험본이 모두 규격대로 나오는 것을 확인했다(99번 문서). 실제 작품이 나온 뒤의 최종 품질은 이미지에 달려 있다.
- 지원서(.hwp)는 열람하지 못했으므로 05는 양식 항목을 보지 않은 일반 문안이다.

## 5. 호랑이 닮음 판정 절차 (기존의 '지인에게 물어보기'를 대체)

시트 A 통과 직후, 쓰기 전에 아래를 하고 `판정기록.txt` 에 남긴다. 이 절차는 침해가 없음을 법적으로 보증하지 않으며, 지원서의 '점검했다'는 문장은 이 절차를 실제로 한 뒤에만 쓴다.

1. 금지 특징 대조: 상모 모자, 리본, 흰 얼굴 테두리, 특정 의상·소품, 시트 T 블록의 '닮으면 안 되는 것' 6항목이 시트에 없는지 눈으로 표시한다.
2. 이미지 역검색: 시트 A의 정면, 3/4, 뒷모습 3장을 이미지 역검색(구글 렌즈 등)에 올려 상위 20건에 같은 캐릭터가 있는지 본다.
3. 키워드 검색: '호랑이 마스코트', '호랑이 캐릭터', '호랑이 일러스트 캐릭터' 이미지 검색 상위 30건과 시트를 나란히 놓고 비교한다.
4. 보조: 가족·지인 2명에게 시트를 보여 주고 무엇이 떠오르는지 묻는다(이것만으로 판정하지 않는다).
5. 기록: 일시, 사용한 검색어, 확인한 건수, 비슷한 것의 유무와 URL, 판정(사용 또는 폐기). 비슷한 것이 있으면 해당 요소를 지우고 재생성한다. 해소되지 않으면 폐기한다.
