# 소재·기술·권리 관련 확인 범위

## 실제 확인한 것

1. 수분 응결을 달리 보이게 하는 표면과 패턴은 기존 기술이다. US20170233285A1은 유리 용기의 외부 김서림 방지 표면을 이용한 패턴을 설명한다. 즉 김서림 패턴이라는 기술 자체를 이번에 처음 발명했다고 주장하지 않는다.
   https://patents.google.com/patent/US20170233285A1/en
2. 포장용 안티포그 코팅은 공급사 자료에 존재한다. 이것은 일반 기술의 존재에 대한 참고이며, 우리의 가상 필름이 전자레인지·밀봉·식품접촉에서 같은 성능을 낸다는 증거가 아니다.
   https://www.acc-coatings.com/wp-content/uploads/2022/10/ACC-Clear-Flexible-Sales-Sheet.pdf
3. 이번 작품의 차별화 가설은 ‘개인 그림이 식사 때의 김과 개봉에서 드러나는 안부 경험’이다. 기존 열반응·숨은 메시지 포장과 얼마나 다른 창의적 구현인지는 별도로 평가할 과제다. 관련 특허의 제조 실시권·식품소재 인증을 확보했다고 말하지 않는다.
4. 실제 생성물의 입력은 자체 생성 사진과 가상 그림이다. 위 기술의 도면·제품 사진·문장을 이미지 생성 참조로 가져오지 않았다.
5. OpenAI 개인용 약관의 출력 권리와 유사 출력 가능성 조항을 확인했다. 이를 모든 제3자 권리가 자동으로 해결됐다는 의미로 확대하지 않는다.
   https://openai.com/policies/row-terms-of-use/
6. 공모전 제공 로고는 이미지 생성에 넣지 않고 정식 PNG를 마지막 조판에서 합성했다. 폴더의 원본 로고와 편집 SVG는 공개 Git 대상에서 제외한다.
