# 재심사 경과와 현재 후보 전략

2026-11-02. 기준은 커밋880deef의 매뉴얼v1이며 후보를 보고 통과 기준을 낮추지 않았다.

## 1. 실제 탈락·재제작

- 기존 「부엌을 접고, 내 삶을 펼치다」:120항목 중24불통과,10미확인. 핵심은 밥의 편의를 주방 전체 소멸로 확대하는 비약과 미래생활 차별성이다. 기획부터 재제작.
- 모듈형 「한 상은 네 번 열린다」:111통과,2불통과,7미확인. 개별 개봉·공동 식사 인과는 개선됐지만 현재 원형 배식트레이 대비 새로움과 생활변화가 약하다는 최종 독립심사를 수용했다. 기획에서 탈락.
- 「갓 지은 편지」:현재 개발후보. 이전 계획의 캐러셀 아이디어를 한 장으로 다시 구성했다. 최초 사진이 인쇄그림처럼 읽혀서 재질을 수정했고, 종이의 원그림을 한 프레임 안에 보조 단서로 추가했다. 수상 확률이나 역사성에 합격 도장을 찍지 않았다.

## 2. 현재 작품의 제안

주제01 ‘미래의 햇반을 만들어밥’. 밥을 데우면, 보낸 사람의 그림이 뚜껑의 김서림·응결 패턴으로 드러나는 메시지형 햇반을 상상했다. 사진의 종이와 필름에 같은 그림을 넣어 개인이 보낸 원그림이라는 해석을 돕는다. 그림·종이는 실제 아이의 작업물이 아니라 AI로 만든 가상 예시다.

현재 사실은 즉석밥·가열·김·개봉이다. 미래 설정은 개인 그림을 포장 표면의 반응 패턴으로 제작하는 서비스다. 실제 출시·식품안전·내열·밀봉·가열성능·전송 장치를 입증한 기술 개발물이 아니다. 일반 상품을 집에 보내는 물류를 초공간 통신 기술로 과장하지 않는다.

## 3. 심리·마케팅을 구현한 위치

- **발견의 순간**: 평범한 한 끼를 여니 사적인 그림이 눈에 들어온다. 큰 우주 배경 대신 제품 표면의 작은 놀라움에 집중한다.
- **인과의 한정**: 따뜻한 밥에서 생긴 수분과 뚜껑의 표현으로 사건이 끝난다. 밥 하나가 집·건강·인간관계 전체를 해결한다고 하지 않는다.
- **친숙함과 낯섦**: 쌀·손·식탁은 현실적인 질감, 그림이 드러나는 표면만 새로운 규칙이다. 매뉴얼 S2·S4·S5를 참고한 적용 가설이다.
- **개인적인 연결**: 종이 원그림과 필름 그림의 대응이 일반 포장 장식과 다른 사적 안부라는 해석을 돕는다. 실제 보낸 사람이 존재했다고 주장하지 않는다.
- **일대일 전송 가설**: ‘네 그림으로 만든 햇반을 보내고 싶다’라는 구체적 문장을 전송 내용으로 잡았다. 실제 사람이 그렇게 공유한 기록은 아직 없다.
- **공개 공유 가설**: ‘미래의 포장이 내 그림을 먹는 순간에 보여준다’는 작은 발견을 소개할 수 있다. 본인의 취향·돌봄을 표현하고 싶은 관객을 가정한다. 실제 효과는 조사 과제다.
- **반복 단서**: 다음에 밥을 열 때 김·필름·작은 그림이 함께 떠오르도록 개봉을 중심에 놓았다. 장기 회상을 측정했다고 말하지 않는다.
- **감정의 방향**: 슬픔·고인 재현·죄책감 대신 살아 있는 사람에게 건네고 싶은 따뜻함과 놀라움을 택한다.

## 4. 독립 최종 기획 검토 요지

사진과 카피만 받은 검토에서 제안 기능은 전달되고, 종이 원그림이 개인성을 보완하며, 이전 두 안의 인과 비약은 피했다고 판단했다. 다만 한 장은 가열 후 한 상태이므로 원래 안 보이던 그림인지까지 증명하지 못한다. 인쇄 장식으로 읽힐 위험과 메시지 포장에 새로움이 집중된다는 한계를 지적했고 **개발후보 유지**로 판정했다.

이 검토는 실제 관객 실험이나 식품소재 성능시험이 아니다. 특정 소재가 실물에서 안전하게 같은 효과를 내는지도 아직 시험하지 않았다.

## 5. 남은 반례와 검증 과제

1. 김서림 그림이 단순 인쇄로 보이지 않는가: 새 관객의 무힌트 답변에서 ‘인쇄’와 ‘물방울’ 해석을 구분한다.
2. 식품의 식욕을 해치지 않는가: 그림·물기가 밥을 더럽히거나 젖은 포장을 우선 떠올리게 하는지 묻는다.
3. 새로움이 충분한가: 기존 온도반응 포장·김서림 패턴과 비교한다. 세계 최초라고 주장하지 않는다.
4. 실제로 전달하고 싶은가: 특정 수신자와 보낼 말을 원문으로 받는다. 제작자의 가설을 관객의 반응으로 세지 않는다.
5. 기억에 브랜드가 남는가:24시간 뒤 브랜드·사건을 무힌트로 회상한다.
