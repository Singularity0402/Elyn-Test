## 창작·마케팅의 검사 범위
A는 ‘멀리 있는 사람에게 식사와 안부를 함께 전하고 싶은 상황’을 겨냥한 가설이다. 핵심은 보내온 그림이 가열 때 나타나는 기능이며, 종이 원그림·김서림·밥을 여는 손이 단서다. 개인 메시지와 일대일 공유가 연결될 가능성을 검토한다. 부모·친구·연인 모두가 같은 감정을 느낀다고 가정하지 않는다.

B는 ‘간편식에도 계절별 맛의 변화를 원하는 상황’을 겨냥한 별도 가설이다.24절기 컬렉션과 네 대표 메뉴의 관계가 중심이다. 맛 취향을 묻는 대화가 공유 동기 가설이며,시즌상품처럼 읽힐 약점도 보존한다.

자동 검사는 위 가설의 문구·파일·증거 일치를 확인한다. 심리학 문헌·AI 시각검토·12명 파일럿을 심사위원 점수나 대중 전체 선호로 바꾸지 않는다. 같은 파일의 기존 검토는 재사용할 수 있지만 새 파일에 자동 승인하지 않는다. 새로운 자유답 의미·화면 진위·사람 출처는 대상 해시와 실제 근거가 있는 검토 기록을 입력해야 반영된다. 파일 이름만으로 닫지 않는다.

## 실행과 판정
검증실행.cmd 또는 python run_checks.py로 실행한다. 새 기록이 생기면 입력함에 넣고 같은 실행으로 갱신한다. 공식 로고는 비공개 캐시에만 보관하고 공개 묶음에 넣지 않는다. 새 원본을 받을 때도 고정 해시가 다르면 재검토를 요구한다.

- 내부 검사 완료: 기준·직접 자산 검사·문구·오류 주입 테스트·관객 도구 동작 검사가 모두 통과.
- 제출 준비: 내부 검사와 공식 요강 확인,실제 제작 화면,공개 SNS/드라이브 열람 확인이 충족.
- 외부 연구 관측 완료:7항목의 실제 증거가 확보된 상태. 반응이 긍정적이라는 뜻과 구분.
- 대회 결과: 실제 발표를 관찰하기 전까지확정하지 않는다.

현재 실제 관객 원답·플랫폼 원자료는 없고,사용자가제공한표는제작화면이아니다. 이 사실은 자동화 작업으로 바뀌지 않는다. 자동화는 같은자료를정확히갱신하고오류를빨리드러내는역할이다.
