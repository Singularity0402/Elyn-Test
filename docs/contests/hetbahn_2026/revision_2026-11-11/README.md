## 먼저 내린 판정
**H2를 대상급 주력작으로 판정하지 않는다.** 좁고 분명한 개봉 문제와 설명의 일치는 개선됐지만, ‘넓은 탭’의 독창성이 부족하다. 기존 이미지와의 이번 비교에서는 **A6 「갓 지은 편지」를 주력으로 유지**한다. 이 판단은 제작자와 별도 AI의 시각·기획 의견이며 실제 심사·수상 결과가 아니다.

## 검수와 근거의 범위
- 실제 이미지 수정 **1회**. 선택 생성원본1122×1402를 보존하고1080×1350으로 조판했다. 4K나 실물 사진으로 부르지 않는다.
- 주 세션은 원본·완성본·실제360폭 비교판을 눈으로 확인했다. 뚜렷한 여분 손가락은 확인되지 않았다. 손가락이 탭을 잡고 다른 손이 용기를 지지하는 장면을 확인했다.
- 별도 AI에 기획서를 주지 않고 새 사진·기존A6·기존H를 비교시켰다. 조판 전 비교 뒤 조판된 H2와360폭을 다시 보여 조건 차이를 바로잡았다. **같은 AI 서비스 내 별도 검토이며 실제 사람·외부 제조 전문가·다른 회사 AI 검증이 아니다.**
- 후속 검토: 주제 전달은 A6>H2>기존H, 제출물 시각 완성도는 A6≈H2>기존H, 독창성은 A6>기존H>H2라는 의견. 숫자 점수나 수상 확률로 바꾸지 않았다.
- 남은 시각 약점: 탭이 작은 주걱처럼 보일 수 있음, 반투명 필름과 보강 탭 경계가 흐림, 밥알의 반복적인 광택. 360폭의 상단·하단 작은 고지는 크게 확대했을 때보다 읽기 어렵다.
- 조판 검사: 한글 글자 영역/충돌/대비, 공식 로고 원본 SHA·합성, PNG/JPG 출력. 별도 Pillow 판독으로 규격·해시·불투명 로고 픽셀·보수적 글자영역 대비·문구·기존파일 유지 재검사.
- 대비 최저 **4.7878**, 내부 기준4.5 이상. 별도 판독기의 불투명 로고 픽셀 **5,978개, 불일치0**. 이 값은 내부 표시 검사이며 실제 사람의 가독성 실험이 아니다.
- 설명241자,500자 이내, 필수 해시태그/계정 포함. 기존A6/B/H 해시 유지.
- 새H2를 이전204개 파일검사 또는120규칙 통과 이미지로 자동 편입하지 않았다. [새 파일검사](독립파일검사.json)의 PASS_FILES_ONLY는 전체 출품 준비 완료나 대상급 판정을 뜻하지 않는다.

## A6도 남겨둔 반론
김서림 속 그림과 종이 그림의 연결이 정서적 장면을 만들지만, 데우기 전후 변화는 문구에 의존한다. 고정된 인쇄 그림처럼 읽힐 수 있고, 보낸 그림을 제품에 적용하는 경험·제조 방식도 미검증이다. 따라서 A6를 우선하는 이유는 이번 비교에서 기획 차별성이 더 강하다는 판단이다. 사람 반응·물성·시장 검증을 통과했기 때문이 아니다.

## 제출 전 실제로 필요한 것
공식 요구에 맞는 실제 AI 서비스 제작 화면 캡처를 별도로 확보해야 한다. 실제 SNS 게시·접수 완료 자료도 이번 차수에 생성하지 않았다. 현재 남은 제품 시험이나 장기 관객 연구를 ‘사진 파일이 깨졌다’는 의미로 해석하지 않고, 파일 완성과 실제 효과의 근거를 구분한다.
