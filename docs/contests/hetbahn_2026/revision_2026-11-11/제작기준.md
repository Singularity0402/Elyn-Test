# H2 수정 이미지 제작 전 기준
2026-11-11. 이전 H는 고리+받침 이미지, H2는 구조 검토였으며 새 포스터는 없었다. 이번에 사용자 요청을 반영한 비교 포스터를 새로 만든다.

- 목표: 작은 탭을 집는 불편이라는 일상 문제를 쉽게 읽히게 한다.
- 필수 수정: 고리·좁은 연결부·별도 고정 받침 제거. 넓은 일체형 필름 탭과 용기를 지지하는 다른 손 표시.
- 제공하지 않는 기능: 재닫힘·한손 개봉·개봉력 감소·기존 밀봉 유지의 검증. 사용자가 원한 덮개형을 구현했다고 부르지 않는다.
- 조판: 공식 원본 햇반30주년 로고와 실제 글꼴 사용, 1080×1350(4:5). 헤드라인 ‘밥 한 끼, / 여는 것부터 편하게.’ 설명 ‘넓은 손잡이와 개봉 시작부를 함께 설계.’ ‘미래 제품 상상 · 실물 성능 검증 전’ 표기.
- 출시 여부: 미래 개봉 구조의 상상 이미지. 시제품 사진·발명 완성품 아님.
- 시각 판정: ①고리/받침이 없는가 ②두 손의 역할과 접촉이 자연스러운가 ③탭-필름 연결을 읽는가 ④밥알/필름의 인공적 재질이나 기형이 심하지 않은가 ⑤한글/로고/4:5/대비가 맞는가.
- 경쟁력 판정은 별도: ‘넓은 탭’만으로 기존 포장 대비 독창성과 대상급 기획이 입증됐다고 하지 않는다. 기존 주력 A와 비교하고, 약하면 보조/비교 후보로 낮춘다.
- 실제 검수: 완성 사진과360폭, 독립 AI 첫인상, 기준별 파일검사. 실제 사람 반응·제품 시험으로 집계하지 않는다.
- 기존 잠금 A6/B와C~H 원본은 덮어쓰지 않는다. 이 새 파일을 기존204검사·120규칙 통과 파일에 자동 편입하지 않는다.
