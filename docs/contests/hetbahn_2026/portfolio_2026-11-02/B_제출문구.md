# B — 스물네 장의 계절
## 작품명
스물네 장의 계절

## 주제 / 형식
01. 미래의 햇반을 만들어밥 / 이미지 한 장

## 작품 설명
날짜로 넘기던 한 해를 밥으로 맛보는 ‘24절기 햇반 컬렉션’을 상상했습니다. 달래보리밥, 옥수수기장밥, 밤버섯잡곡밥, 무흑미밥은 네 계절을 대표하는 창작 메뉴 예시입니다. 네 공기 바깥의 절기 고리와 중앙의 24를 연결해, 절기가 바뀔 때 새로운 한 공기를 여는 경험을 표현했습니다. 음식 사진은 AI로 생성·수정하고 달력과 한글, 공식 로고는 별도 조판했습니다. 24종 전체의 실물 사진이나 실제 출시 예정 제품을 뜻하지 않습니다.

## 사용한 AI 서비스 / 활용
OpenAI Codex 내장 이미지 생성 기능. 네 계절의 창작 밥 사진을 생성하고 그릇 크기·배치와 봄 메뉴 재료 표현을 수정했습니다. 24절기 명칭·눈금·한글·공식 로고는 생성 후 별도 조판했습니다.
