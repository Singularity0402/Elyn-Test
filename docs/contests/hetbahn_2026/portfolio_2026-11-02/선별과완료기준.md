# 다중 출품의 선별·완료 기준 — 2026-11-02

## 1. 이번 사용자 지시의 반영

출품 수가 제한되지 않는다는 공식 요강을 다시 확인했다. 같은 사람이 여러 작품을 내면 최고 득점 한 편만 본선에 진출한다. 따라서 서로 다른 제안의 완성작을 함께 내는 전략을 택하되, 이미 기획 탈락한 주방안·모듈안을 제출 수를 채우려고 복구하지 않는다. 같은 편지안의 재질 수정본을 별도 작품으로 중복 계상하지 않는다.

기준을 120개에서 더 늘려 합계로 품질을 주장하지 않는다. 기존 매뉴얼 v1을 보존하면서, 이번에는 다음 네 영역의 상태를 분리해 완료를 판정한다.

## 2. 네 가지 판정 영역

|영역|지금 수행할 일|완료의 의미|현재 작업 밖에서 남는 것|
|---|---|---|---|
|공식 형식·표시|비율·공식 로고·상상 고지·문구·파일 확인|각 완성 파일의 제작 형식 확인|참가자 자격·본인 정보·동의·실제 접수|
|통제 가능한 화면 품질|밥알·물성·손·그림 대응·대비·배치 보정|새로운 심각한 제작 결함이 남지 않은 파일|실물 제품의 소재·밀봉·가열 시험|
|창작·포트폴리오 선별|다른 제안, 가까운 선행 표현, 무힌트 해석, 장단점 비교|각자의 장점으로 출품할 후보 선별|최상위 독창성의 최종 심사 판단|
|관객·시장·역사성|기존 사전등록·관찰 도구를 보존|측정 설계와 기록 도구 준비|실제 새 관객·공유·회상·장기 반응|

‘작품 제작·선별 완료’는 위에서 통제 가능한 파일 제작과 제출 문구 정리를 마친 상태다. 관객 효과·당선·역사성 실측까지 끝났다는 뜻으로 쓰지 않는다. 미확인은 외부 결과를 얻기 전까지 그대로 둔다.

## 3. 출품작별 역할

- A 「갓 지은 편지」: 개인의 그림을 따뜻한 식사 때 발견하는 미래 제품. 사적인 연결·촉각적 김서림의 발견이 강점. 금속성 반사·젤 같은 밥알·원그림 대응·고지 대비를 보완한다.
- B 「스물네 장의 계절」:24절기별 창작 햇반을 음식 달력으로 보여주는 미래 컬렉션. 계절의 맛·반복해서 여는 경험·소장하고 싶은 라인업이 강점. 네 대표 예시와24종 제안을 혼동시키지 않고, 달력 글자·음식이 겹치지 않아야 한다.

두 안의 수상 사건이 통계적으로 독립이라고 가정하지 않는다. 다중 출품의 이점은 둘 중 하나를 억지로 제거하지 않고 서로 다른 제안의 심사를 받을 수 있다는 점이다.

## 4. 최종 선별에서 제외할 것

- 단순 색·재질·타이포만 다른 같은 작품의 중복 출품.
- 제품과 무관한 마법, 음식·위생을 해치는 장면, 원형 결합 자체만 새롭다고 주장하는 용기안.
- 기술·건강·환경 성능을 실제 검증 없이 확정하는 이미지.
- 이름·숫자·사진 내용이 서로 맞지 않는 시안.
- 보완 가능한 결함을 확인했는데도 남긴 파일.
