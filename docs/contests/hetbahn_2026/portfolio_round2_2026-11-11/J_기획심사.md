# J — 내일의 논 / 제작 전 심사
주제02. 햇반 공급 기반의 다음30년을 바다 위 담수 재배구획으로 상상하는 장면.
고객·참여자: 다음 세대에도 밥을 공급하고 싶은 농가/브랜드와 식탁의 소비자. 당장 더 싼 쌀이라는 주장 아님.
최선대안: 육상 계약재배·기후적응 품종·기존 관개/시설농업. 이것보다 경제적이라고 판정하지 않음.
핵심: 실제 크기 논/담수와 바다의 분리/그 논 위 점심의 햇반이 한사진에 연결됨. 바다 위 농업이용기술의세계최초 주장은 안함.
현실접점: FAO의 기존 부유식 농업은 채소/향신료/모종 등의 선행이며, 이 해상 벼재배·파도내구·염분차단·담수공급·수확수익성의 입증이 아님.
중요가정: 견고한 플랫폼, 담수·토양 담는 구획, 파도/염분 유입차단, 작업동선/안전난간, 도정/취반/유통까지 공급연결. 현재원가/생산성/환경편익수치 없음.
내부판정: 실현성연구가많이남는미래비전 후보. 즉시상용화후보로등급올리지않음. 실제기업확장보다는시각상상력축을담당.
탈락/수정: 미니섬/바닷물에벼를직접심은이미지/식품위사람/난간없는위험한아동/공급관계빠진일반풍경이면생성수정.
