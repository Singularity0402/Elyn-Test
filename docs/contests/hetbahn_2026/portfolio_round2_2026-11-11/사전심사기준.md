# 2차 후보 제작 전 심사 기준
2026-11-11. 사용자: 기존 강한 후보를 보존하며 가능한 새 후보와 재제작본을 더 만든다. 이전 이미지·원본·120규칙을 덮어쓰지 않는다.

## 먼저 탈락시킬 것
- 새 부품/모양만 있고 최선의 대체재보다 쓸 이유가 없는 제품.
- 작동하지 않는 효능을 실제 성능으로 포장하거나, 김밥/컵반/일반 그릇보다 수고만 늘리는 제안.
- 로고를 치우면 다른 업종이 더 자연스러운 장면.
- 주방 소멸/우주/로봇/홀로그램/미니도시/자가발열 등 이미 검토한 상투안.
- 맛·접촉·무균·가열·환경/건강 수치의 근거 없는 약속.

## 새 기획 심사
상품/생활안 각각의 대상·상황·최선대안·구매/참여 이유·새행동·한화면 장면·실행구성·비용/권리·반론을 먼저 쓴다.
별도 AI 기획과 반대 검토를 참고하되 창작자 판단을 독립 검토자/실제 관객으로 바꾸지 않는다.
전제가 다른 새 안 가운데 실제 제출용 그림으로 성립하는 것을 택한다.

## A7 보강 목표
A6 강점은 유지하며 ‘가열하면 그림이 드러남’이 문구에 의존하는 약점을 개선한다.
한 식탁에 동일 디자인의 두 예시 상태(가열 전 매끈한 빈 필름/가열 후 김서림 속 그림)와 같은 원그림을 제시한다.
A6는 별도 보존하고 A7은 비교해 선택한다. 새 전제로 만든 후보와 A의 표현 보강을 다른 수로 센다.

## 이미지 제작 후 필수
원본/정확프롬프트/실제생성회수 보존 → 무문구 독립검토 → 결함별수정 → 공식로고·정식한글·1080×1350 조판 → 축소가독성/실물오인/기존안비교 → 파일·출품문구·묶음검사.
새이미지에 기존120검사 PASS를 복사하지 않는다. 규정검사·내부기획심사·실제관객/실제품 근거를 별개로 적는다.
실제 생성화면 캡처·공개게시·접수 완료는 실행 자료가 있을 때만 기록한다.
