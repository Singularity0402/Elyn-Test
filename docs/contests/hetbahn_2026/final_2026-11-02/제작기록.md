# 제작 기록 — 「부엌을 접고, 내 삶을 펼치다」

제작일: 2026-11-02 (한국 날짜)

## 작품의 판단 근거

출품 주제는 ‘02. 햇반이 지을 미래를 보여줘밥’. 한 장 안에서 ‘제품의 개봉 → 집의 변화 → 사람에게 생기는 자리’를 잇는다. 햇반의 익숙한 개봉 동작을 건축 규모의 접힘과 연결하고, 사진의 불가능한 부분은 그 한 관계에 집중했다. 음식·손·가족·빛은 현실적인 질감으로 유지했다.

카피는 ‘부엌을 접고, 내 삶을 펼치다.’다. 햇반의 다음 30년을 조리 성능이 아니라 생활의 자율성으로 해석했다. 접히는 부엌은 실제 제품 기능을 주장하지 않는 시각적 은유다. 하단과 신청서에 이를 명시했다.

시선의 순서는 공식 브랜드/카피, 오른쪽의 접힌 주방, 왼쪽의 가족, 전경의 한 끼로 설계했다. 독해의 용이성·예상 밖의 크기 전환·따뜻한 생활 보상을 함께 노린 디자인 판단이다. 관객 실험을 실시한 결과나 입상 예측 수치가 아니다.

## 조사와 선행 발상 점검

- 공식 공고는 이미지와 영상을 별도 부문으로 나누지 않는다. 이미지 한 장의 4:5 출품이 가능하다. 심사 비중은 창의35/주제20/AI20/완성10/투표15다.
- CJ의 30주년 자료에서 백미·잡곡·미니밥·소프트밀 등 여러 생활 수요를 포괄하는 브랜드 확장과, 미래의 식생활을 바꾸겠다는 방향을 확인했다. 특정 건강 효능이나 발표된 신제품을 출품작의 가상 기능으로 가져오지 않았다.
- 이전 기획 「갓 지은 편지」는 세부 원리 설명이 필요한 캐러셀 기획이었다. 이번 요청은 한 장으로 다시 설계했다.
- 독립 기획 두 작업에서 ‘접히는 주방’이 모두 제안됐다. 따라서 접이식 주방 자체가 유일무이한 발상이라고 간주하지 않았다. 차별화의 중심은 실제 제품의 개봉과 건축의 접힘을 같은 선으로 잇는 화면 구성이다.
- ‘부엌을 접고’, ‘내 삶을 펼치다’와 즉석밥 광고·folding kitchen/peeling kitchen 관련 제한적 웹 검색을 했다. 직접 일치하는 작품을 확인하지 못했지만, 검색은 완전하지 않다. 시간 절약·가족의 여유는 기존 식품 광고에 널리 쓰이는 주제다. 세계 최초나 무유사성을 주장하지 않는다.
- 기존 광고의 이미지·문장·캐릭터나 유명인의 얼굴/이름을 생성 참조로 사용하지 않았다. 등장 인물은 합성된 가상 인물이다.

## 실제 생성·수정 이력

1. **1차 생성**: 제품 뚜껑과 방 크기의 주방을 한 장의 은박 흐름으로 연결. 결과의 세로 비율이 지나치게 길고, 주방이 가족 머리 위에 떠 있는 듯 보였다. 선택하지 않음.
2. **2차 수정**: 4:5에 가까운 폭으로 장면을 재구성. 접힘을 오른쪽 벽으로 이동해 사람의 생활 공간을 분리. 독립 검토에서 주방의 접힘이 곡면 장식으로 읽히고, 밥알과 용기가 과장됐다는 지적을 받음.
3. **3차 수정**: 용기 높이·밥알 모양·김을 보정. 주방을 얇은 면과 명확한 접힘으로 정리. 상부장만 접힌 듯 보이는 문제가 남음.
4. **4차 수정 — 최종 선택**: 싱크대·하부장 면 자체의 기울기를 함께 바꿔, 주방이 접히는 동작을 더 분명하게 정리. 원본 사진 1122×1402.
5. **최종 조판**: 한글 문구는 이미지 생성과 분리해 S-Core Dream으로 조판. 공식 1080×1350 투명 PNG를 잘라내거나 색을 바꾸지 않고 전체 화면에 얹음. 최종 PNG와 JPG는 동일한 작품이다.

생성 프롬프트 전문은 `생성프롬프트.json`에 있다. 최종 선택 이미지는 `02_생성원본.png`에 원래 픽셀 크기로 보존했다. 앞선 미선택 결과는 이미지 생성 서비스의 이 대화 기록에 남아 있다.

사용 도구: OpenAI Codex 내장 이미지 생성 기능(사진 생성·수정), 로컬 조판(공식 로고와 한글 배치). ComfyUI·Flow·Gemini로 제작했다는 주장은 하지 않는다. 주최 측 로고를 생성 모델의 입력으로 넣지 않았다.

## 검수 범위와 결과

- 제작 의도를 주지 않은 새 검토 작업에서 즉석밥, 개봉, 가족과 놀 여유라는 의미를 읽었지만 초기 시안의 인과관계는 불명확하다고 지적했다. 해당 지적을 후속 수정에 반영했다.
- 식품 가까이에 인물·건물·폐기물이 들어가지 않도록 구성했다. 인물은 실제 생활 공간의 바닥에 있다.
- 최종 수동 검수: 한글 오타, 손·다리의 심한 형태 오류, 음식 오염, 로고 누락을 확인했다. 외부 심사위원/일반 소비자를 대상으로 한 검증은 실시하지 않았다.
- 기술 검수는 `검수결과.json`. 4:5(1080×1350), 원본 해시, 최종 파일 해시를 기록했다. 공식 로고의 완전 불투명 픽셀 5,978개를 비교해 RGB 불일치 0개를 확인했다. 반투명 가장자리는 공식 PNG의 알파를 그대로 합성했다.
- 생성 원본은 1122×1402다. 최종 SNS 규격으로 소폭 축소했다. 이를 네이티브 4K 원본이라고 표시하지 않는다.
- 사용 글꼴은 S-Core Dream 7/4. PC에 설치된 라이선스 문서에서 광고·상업 사용 허용을 확인했다. 글꼴 파일 자체를 이 저장소에 별도로 배포하지 않는다.
