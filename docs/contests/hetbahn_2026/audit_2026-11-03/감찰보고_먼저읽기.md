## 1. 감찰에서 확인한 준비 부족
1. **D10의 오독:** 원문은 비교작 대비 기능·행동·관계의 차이를 기록하고 과장하지 말라는 요구다. 이를 ‘최상위 독창성의 외부 입증’으로 바꿔 미확인 처리했다. 별도 AI 감찰도 같은 오류를 지적했다. 원래 규칙으로 재판정한다.
2. **설계 근거의 연결 오류:** 이전 최종작 설명이 연결한 심리 실행 문서는 탈락한 모듈안 중심이었다. 논문의 적용 범위를 A/B 최종작에 맞춰 다시 쓴다.
3. **실행 준비의 공백:** 관객 계획은 있었지만 기존 HTML은 주방안과 이전 편지안을 보여줬다. 현재 A/B의 실험 도구가 아니었다. 현재 작품 해시·고정 배정·중단 기록·24시간 회상·원답 내보내기를 갖춘 새 도구로 분리한다. 기존 실험 도구 검사 결과는 새 실험 결과로 재사용하지 않는다.
4. **사진 물성 기준의 느슨함:** A의 쌀알 광택·용기 재질·두 그림의 대응이 남아 있었는데 문서상 내부 통과와 이미지의 강점을 충분히 구별하지 못했다. A4 보정 실패는 탈락시키고, A5에서 사진을 새로 생성했다. 문구는 브랜드와 가열 기능을 명시하고, 두 작품의 가상 제품 고지를 키웠다.
5. **완료 보고의 모호함:** 파일 제작, 관객 데이터 수집, 수상·역사성 검증은 다른 상태다. 현재 요청에서 사용자가 실제 관객 원답·공개 게시 주소가 ‘없음’이라고 확인했다. 기록을 늘려 이 공백이 해소됐다고 쓰지 않는다.
