# 관객 검증 도구

실제 관객 검증은 아직 실행하지 않았다. `동작검사.cjs`의 DOM/브라우저 검사는 실제 사람의 응답이 아니다.

1. 주세션에서 `../A_갓지은편지.png`, `../B_스물네장의계절.png`를 확정하고 `protocol.js`의 두 SHA256과 `hash_status`를 갱신한다. 현재 해시는 주세션에서 확정한 A6/B 수정본 기준이다. 내용·해시를 바꾼 수집은 새 `protocol_id`를 부여한다. 수집 도중 프로토콜을 바꾸지 않는다.
2. 이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1 --directory ..` 실행 후 같은 기기의 Chrome에서 `http://127.0.0.1:8765/관객검증/관찰.html`을 연다. 파일 직접 열기는 지원하지 않는다. 휴대폰 화면으로 검증하되 모바일 브라우저를 직접 쓰려면 보안 연결(HTTPS)에서 이 폴더와 두 이미지 파일만 제공해야 한다. 화면 크기는 기록에 남는다.
3. 새 성인 12명에게 P01~P12를 한 번씩 배정한다. 코드별 A6/B6 배정은 프로토콜에 고정되어 있다. 진행자는 작품 제목·브랜드·의도·정답·음식 취향을 먼저 설명하거나 질문하지 않는다. 각 관객은 한 장만 3초 본다. 동의와 이전 노출 자가신고를 받고 자유답을 수집한다. 이전 노출자는 기록을 보존하되 신규표본에서 제외한다. 익명 코드만 사용하고 실명·이메일은 받지 않는다.
4. 첫 응답 뒤 JSON을 내려받고, 같은 기기·브라우저·주소·코드로 24시간 뒤 돌아와 무힌트 회상 후 JSON을 다시 내려받는다. 이미지는 다시 보여주지 않는다. 내려받기 파일은 사람에게 전달하는 동작이며 서버 업로드 기능은 없다. 브라우저 데이터를 지우거나 다른 기기로 옮기면 잠금이 이어지지 않는다. 진행자가 코드 발급·중복 참여·시간 준수를 별도로 확인한다. 기기 시계 조작은 도구만으로 입증할 수 없다.
5. 실제 응답만 모은 별도 디렉터리를 집계한다: `python 응답_집계.py "실제응답폴더" --output "품질감사.json"`. 출력은 입력 폴더 밖에 둔다. 같은 ID의 첫/회상 JSON을 함께 넣으면 중복으로 모두 제외하므로 입력에는 마지막 파일 하나만 두고 이전 파일은 별도 보관한다. 원답과 원본 JSON 텍스트는 보고서에도 그대로 남는다. 정답은 자동 채점하지 않는다. 기록 품질 유효성과 실제 사람 응답의 외부 출처 확인은 별개다. 진행자는 실명 없이 모집/현장 확인 이력을 따로 보관한다.

QA 실행: `node 동작검사.cjs`. 번들 Playwright와 설치된 Chrome을 완전히 격리한 임시 환경에서 실행한다. 모든 자료는 메모리 응답으로 제공하며 오프라인 상태에서 검사한다. 실제 서비스나 사용자 Chrome을 조작하지 않는다. 최종 이미지가 없을 때만 기존 portfolio 파일을 QA 메모리 입력으로 쓰며 결과에 경로를 표시한다. 최종 확정 뒤 `node 동작검사.cjs --final-only`로 반드시 다시 검사한다. 3초는 실제로 기다리며 24시간 경계만 QA 시계를 앞당겨 확인한다. 탭 숨김은 headless DOM에서 visibilitychange를 주입해 중단 처리를 확인한다.

수동 QA 주소는 `관찰.html?qa=1`이다. QA는 `record_kind=qa`, `qa_` 파일명과 별도 localStorage 이름공간을 쓴다. **QA JSON을 실제응답 디렉터리에 저장하지 않는다.** 자동 검사는 OS 임시 폴더만 쓰고 검사 뒤 제거한다. QA 기록은 집계기에 섞여도 표본에서 제외된다.

localStorage 키는 `observer:<protocol_id>:<participant|qa>:<참가코드>`다. 새로고침·재방문·동시 창·노출 중 중단은 이벤트로 남기고 재노출을 허용하지 않는다. 중단 기록을 지우고 재시도하지 않는다. 노출시간은 2800..3800ms만 품질조건으로 인정하며 누락·중복·해시·프로토콜·배정·동의를 검사한다. 회상이 아직 없으면 최초 응답 품질과 24시간 회상 완결 여부를 별도로 표시한다.

각 안 5/6은 내부 제작 목표이며 통계보장·학술 유의성·수상확률이 아니다. 표본 0명에 결과나 비율을 만들지 않는다. 미확인 L06은 실제 경쟁작 필수 조건이 아니라 동등노출 비교이므로 A/B 파일럿 비교로만 기록하고 경쟁대회 우위는 주장하지 않는다. 고정 계획 원문은 `../../portfolio_2026-11-02/실제관객검증_미실행.md`다.
