이 순위는 상금·마감·새 도구와 결과물의 부담에 대한 판단이다. 경쟁자 수나 수상 확률을 계산한 결과가 아니다. 홈페이지 참가자 수를 실제 출품작 수로 바꾸지 않았다.

## 현금을 받는 시점과 권리
- 위 다섯 대회 규정은 서류 확인 후 우송 또는 은행계좌 전자 지급 경로를 둔다. 필요 서류 수령 후60일 이내 지급 조항이 있으나, 이는 오늘부터60일 또는 마감 후60일이라는 뜻이 아니다. 해외 수상자에게 W-8BEN 등 세금 서류를 요구할 수 있고 수수료·세금은 별도다. 실제 수령 순액이나 적용 세율은 계산하지 않았다.
- 발표는 UGREEN **12/6 미국시간 전후**, PayPal **12/21 미국시간 전후**, Snap **12/17 미국시간 전후**, Kiroween **2027/2/3 미국시간 전후**, Codegeist **2027/2/15 미국시간 전후**다. 발표일은 확정 입금일이 아니다.
- 소유권은 창작자에게 남는 구조이나 심사·대회 홍보 이용권이 따른다. Kiroween·PayPal은 공개 오픈소스 제출이 요구된다. 타 대회용 완성작이나 독점 납품 코드를 그대로 넘기는 계획은 세우지 않는다.
- **이번에 선별한 신규 후보 중 11월 안에 입금이 확정된 건은 없다.** 빠른 제작 가능성과 빠른 현금 수령을 구분한다.

## 기존 작업과의 연결
기존8건 계획과 간판·세종·조달청 게임의 최신 커밋을 읽고 보존했다. 간판은 이번에 공식 요강을 다시 열어 **수상자 시상식 참석 필수**, 상금 계좌 지급과 별도 발표평가 없음, 실제 과정 녹화가 후보작에 필요함을 확인했다. 사용자는 시상식 참석을 허용했으므로 그 조건만으로 제외하지 않는다. [간판 요강](https://xn--ai-vs1i84a86y3mi7lxqfa73b312f.com/info.asp)

햇반은 [H2 후속 검토](../hetbahn_2026/product_review_2026-11-11/H2_후속판정.md)에서 넓은 필름 탭을 개발 비교 기준으로 정하고, 단순 고정 힌지/앞 끝단 직결형의 길이 부족 반례를 수식·1,000점 검산·독립 AI 반론으로 좁혔다. 실물 성능이나 새 출품 사진 완성이 아니다.

## 제작 전에 적용할 공통 절차
1. 자격·AI 사용·개별 현금상·정확한 마감·현장 의무·권리·지급 경로의 공식 근거를 잠근다. 원문이 없으면 제작 착수를 보류한다.
2. 한 사람의 한 문제를 택하고 가장 강한 대체재를 비교한다. “AI로 만들었다” 자체를 구매 이유로 삼지 않는다.
3. 심사 항목을 실제 제출물에 대응시킨다. 기술 필수 대회는 기능을 먼저 실행하고, 그림 대회는 규정에 맞는 실제 생성·수정 기록을 남긴다.
4. 독창성은 선행작·기존 제품을 검색해 차이를 쓰고, 독립 검토자에게 기획 의도를 감춘 첫 인상을 확인한다. AI 검토를 사람 반응으로 집계하지 않는다.
5. 실패·누락·재현을 검사한 뒤 설명문을 완성한다. 포스터·목업·지역 모형의 성공을 실제 제품·시장 성공으로 확대하지 않는다.
6. 원본과 과정 증빙, 필수 개인정보·서명, 접수확인 자료를 구분해 보관한다. 공개 게시·접수는 실제 계정과 최종 제출물로 실행해야 하며 이번 조사에서 실행하지 않았다.

이번 자동 확인은 마감 시간대 변환·기록 상태의 일관성·링크 형식과 파일 연결 검사다. 웹 규정은 사람이 읽듯 직접 대조했으며, 자동 검사가 수상·수령 자격·실제 입금을 인증하지 않는다.
