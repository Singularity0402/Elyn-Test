### A-3. 기획의도

```
공공조달은 우리 곁에 있지만 눈에 잘 띄지 않습니다. 학교의 책상, 도서관을 짓는 공사, 소방서의 새 장비, 재난 때 도착하는 담요, 공장에 쓰이는 비철금속이 어떤 길로 오는지 아는 사람은 많지 않습니다.

이 게임은 설명 대신 손으로 알게 하려고 만들었습니다. 회색으로 멈춘 동네의 물건을 문질러 색을 되돌리면, 그 물건이 어떤 상황에서 어떤 방법으로 도착했는지 고르는 장면이 나옵니다. 종합쇼핑몰, 나라장터 입찰, 혁신제품 시범구매, 긴급 조달 조치, 비축물자 방출 다섯 가지를 한 번씩 만납니다.

전하려는 말은 하나입니다. 필요한 것이 필요한 때 도착해 있는 것은 우연이 아니라 미리 준비된 길이 있기 때문이라는 것. 마지막 장면에서 처음의 회색 동네에 색이 돌아오며 “오늘 하루도, 미리 도착해 있었습니다.”라는 문장이 남습니다.

게임 속 상황, 장소, 물건은 모두 이해를 돕기 위해 만든 가상입니다. 제도 설명은 조달청 누리집과 정책브리핑의 공개 자료를 바탕으로 썼고, 게임 안에서 ‘가상 상황’과 ‘실제 제도’를 따로 표시했습니다.
```

### A-4. 게임 설명

```
회색으로 멈춘 동네에서 시작합니다. 플레이어는 하루 동안 다섯 장면(아침의 학교, 한낮의 도서관 공사장, 오후의 소방서, 저녁의 임시 대피소, 밤의 공장 마을)을 지나며 회색 물건을 문질러 색을 되돌립니다.

앞의 네 장면에서는 물건을 모두 되돌리면 ‘가상 상황’ 카드가 열리고, 세 가지 도착 방법 가운데 알맞은 것을 고릅니다. 맞히면 실제 제도 설명이 나오고, 틀리면 점수 감점 없이 힌트가 나옵니다.
- 학교 책상 20개가 모자란 상황은 종합쇼핑몰 주문
- 도서관 별관 신축 공사는 나라장터 입찰
- 상용화 직전의 소방 드론은 혁신제품 시범구매
- 산불 대피소의 담요와 생수는 긴급 조달 조치

마지막 밤의 공장 마을에서는 같은 방식이 통하지 않습니다. 공급이 막혀 문질러도 색이 오래 가지 않습니다. 플레이어가 닫혀 있던 창고를 열면, 위기에 대비해 미리 쌓아 둔 비철금속(비축물자)이 있었고 마을 전체에 색이 돌아옵니다. 이어서 처음의 가로등과 나무에도 색이 돌아오고, 다섯 가지 도착 방법을 정리한 ‘도착표’ 카드를 이미지로 저장할 수 있습니다.

한 판은 약 2분이며, 실패해서 끝나는 장면이 없습니다.
```

### A-5. 주요 플레이 방식

```
조작은 문지르기(마우스 드래그, 터치 드래그)와 누르기뿐입니다. 키보드만으로도 할 수 있습니다. Tab 키로 물건을 고르고 Enter 키로 색을 되돌리며, 도착 방법은 숫자 1, 2, 3 키로 고릅니다.
1. 회색 물건을 문질러 색을 되돌립니다(물건마다 서너 번 쓱쓱). 가만히 있으면 문질러야 할 곳에 노란 점선이 나타납니다.
2. 물건 세 개의 색이 모두 돌아오면 가상 상황 카드와 도착 방법 세 가지가 나옵니다.
3. 알맞은 방법을 고르면 실제 제도 설명을 읽고 다음 장면으로 갑니다.
4. 다섯 번째 장면에서는 문지르기만으로 되지 않으니 힌트를 따라 창고를 엽니다.
5. 마지막에 다섯 가지 방법을 정리한 도착표를 확인하고 PNG 카드로 저장할 수 있습니다.
소리는 꺼도 모든 내용이 글자로 나오며, 화면에 자막이 함께 표시됩니다. 설치, 로그인, 인터넷 연결이 필요 없고 index.html 하나로 실행됩니다.
```

### A-6. 조달청·조달정책 반영

```
게임에 반영한 조달청의 제도와 업무는 다섯 가지입니다.
1. 종합쇼핑몰(다수공급자계약): 조달청이 여러 업체와 미리 계약해 둔 상품을 학교 같은 수요기관이 나라장터 종합쇼핑몰에서 비교해 주문합니다. 금액이 큰 경우 2단계 경쟁을 거치는 점도 설명합니다.
2. 나라장터 입찰: 공사나 큰 용역은 입찰 공고를 올리고 자격을 갖춘 업체가 전자입찰로 경쟁합니다. 나라장터가 공고부터 계약, 대금 지급까지 온라인으로 처리하는 시스템임을 알립니다.
3. 혁신제품 시범구매: 조달청이 상용화 직전 제품의 첫 구매자가 되어 각 기관에 제공하고, 기관이 시범 사용으로 성능을 검증합니다.
4. 긴급 조달 조치: 2025년 산불 때 한시로 시행된 긴급조달지침(긴급입찰 공고 기간 단축, 종합쇼핑몰 바로 구매, 납품검사 한시 면제)을 설명하되, 한시 조치였다는 점을 분명히 밝힙니다.
5. 비축물자: 알루미늄·구리·납·아연·주석·니켈 6종의 비철금속을 비축해 실수요 제조업체와 중소기업 단체에 판매하는 사업과, 전매 금지·업체별 주간 판매 한도·재고 보충 시 방출 중단 공지를 설명합니다.
게임 속 상황은 가상이며 실제 구매 방식은 물품과 금액, 상황에 따라 다르다는 안내를 결말 화면에 넣었습니다. 특정 기업과 개인, 법령 조항은 넣지 않았습니다.
```

### A-8. 사람이 한 일 (사용 프로그램 칸 바로 앞에 붙인다)

아래 문장은 **응모자가 실제로 한 것만 남기고, 하지 않은 문장은 지운다.** 지운 문장이 있다고 해서 다른 문장을 고치거나 덧붙이지 않는다. 날짜와 횟수는 02 문서의 기록표에 먼저 적어 두고, 신청서에는 문장만 옮긴다. 한 문장도 남지 않으면 AI 활용 내용이 곧 제작 내용이 되어 ‘직접 기획·제작’ 요건 시비가 생기므로, 제출 전에 02 문서의 플레이테스트부터 한다.

```
사람이 한 일입니다.
1. 응모자가 공모 주제와 소재(다섯 가지 조달 방법 가운데 무엇을 넣을지, 비축을 마지막에 두는 순서)를 정하고 AI가 낸 안을 취사선택했습니다.
```

## B. 내부 메모 (제출하지 않음)

### B-1. 무엇이 바뀌었나 (이전 안 「주석의 울음」 폐기)

심사위원장 검수에서 이전 안은 (1) 시나리오 부문 작품과 같은 제목·세계관·소재, (2) 조사 JSON이 가장 위험하다고 분류한 비축 시뮬레이션, (3) 규칙이 복잡하고 PC 마우스 전용, (4) 공무원 희화화·AI 비판으로 읽힐 소지, (5) 청각 소재와 방언으로 지적받았다. 그래서 소재와 구조를 새로 짰다. 이전 안은 `_보관/구버전_주석의울음_index.html`에 남기되 제출하지 않는다.

| 쟁점 | 이전 안 | 이번 안 |
|---|---|---|
| 시나리오와의 관계 | 같은 제목·세계관·소재 | 제목, 시대(현재), 장소, 인물(없음), 소재가 모두 다르다. 시나리오의 ‘주석의 울음’, 서해 비축기지, 석주·도윤은 나오지 않는다. |
| 조사 JSON 권고 | 가장 위험한 B안(비축) | A안의 구조(회색→색 복원, 일상 사물, 한 가지 규칙)를 따르고, 비축은 마지막 반전 장면의 한 요소로만 쓴다. |
| 규칙 복잡도 | 규칙 5개, 6~8분 | 규칙은 ‘문지르기’ 하나, 선택은 세 가지 중 하나, 약 2분. |
| 입력 | 마우스 전용, 16:9 고정 | 마우스·터치·키보드, 가로·세로 화면 모두. |
| 주제 범위 | 비축 하나 | 종합쇼핑몰, 나라장터, 혁신제품, 긴급 조달, 비축의 다섯 가지. |
| 기관 이미지 | 전매 적발, 서두르는 국장, AI 예측 비판 | 사람 인물이 없고, 제도를 긍정·중립으로 설명한다. AI를 비판하지 않는다. |
| 소리 의존, 방언 | 귀가 어두운 선배, 충청 방언 | 소리 없이도 전부 성립하고, 표준어만 쓴다. |
| 정책 사실 | 언론 경유, 미확인 | 조달청 누리집 확인분과 확인 상태를 B-6에 문장별로 적었다. 수치는 쓰지 않았다(‘5일’ 하나). |

### B-2. 심사 경험 설계 (첫인상 → 호기심 → 반전 → 회수 → 한마디)

| 단계 | 장면 | 의도 |
|---|---|---|

### B-8. 알려진 한계 (정직하게)

- **사람이 직접 한 플레이테스트가 아직 0회다.** 이번 작업에서 한 것은 문법 검사(`node --check`)와, 브라우저 패널에서 포인터·키보드 이벤트를 코드로 쏘아 다섯 장면을 끝까지 돌린 시험(콘솔 오류 0), 375×812와 1920×1080 화면 폭에서의 배치 확인, 카드 PNG 생성 확인이다. 실제 마우스·터치패턴, 실제 휴대폰, 엣지, 소리는 확인하지 못했다.
- 문지르는 감도(몇 번 쓸어야 색이 도는가)는 코드로만 정했다. 02 문서의 플레이테스트에서 ‘너무 오래 걸린다 / 너무 쉽다’를 적는다.
- 그림은 단순한 벡터 일러스트다. 영상미 점수에서는 한계가 있다. 이미지 생성 AI로 배경을 바꾸는 확장은 가능하지만 이번 제출에는 넣지 않았다(요강상 의무 아님, 권리 증빙 부담이 늘어남).
- 설명 문장은 글자가 많은 편이다. 초등 저학년은 읽기 어렵다.
- 마스코트 미사용, 한 판 약 2분이라 깊이가 얕다는 평가가 가능하다.
