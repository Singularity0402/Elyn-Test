# 01_시연영상_촬영대본 — 「미리도착한하루」 시연영상 (60초)

요강 원문 규격: **1분 내외 / 1080p 이상.** 접수 가이드의 파일명 예시가 `.mp4`이므로 MP4(H.264)로 낸다. 파일명 `AI게임_시연영상_미리도착한하루_성명.mp4`.

원칙은 세 가지다.
1. **실제로 이어서 플레이한 한 판을 녹화한다.** 이전 안과 달리 `?jump=` 같은 건너뛰기 주소가 없으므로, 영상은 한 번의 실제 플레이에서 나온다. 편집은 대기 시간을 자르는 컷만 쓰고, 속도 변경은 쓰지 않는다.
2. **무음에서도 성립한다.** 게임이 화면에 자막(‘회색 물건을 문질러…’ 등)을 직접 띄운다. 소리는 보조다.
3. **게임 밖 이미지·음악·외부 소재를 넣지 않는다.** 그래서 영상 쪽 권리 증빙이 필요 없다. 편집기에서 넣는 것은 자막 두 줄과 마지막 작품명 카드뿐이다.

## 1. 영상의 흐름 (심사위원이 거치는 순서)

| 단계 | 시간 | 보여 주는 것 | 심사위원이 느껴야 하는 것 |
|---|---|---|---|
| 첫인상 | 0:00~0:03 | 어두운 화면 한가운데 회색 모형 동네. 질문 “이 동네는 왜 회색일까요?”. 아무도 만지지 않았는데 노란 빛이 스스로 가로등과 나무를 문질러 색을 입힌다. | 로고가 아니라 움직이는 물체로 시작한다. 다르다. |
| 호기심 | 0:03~0:37 | 손으로 가로등을 문지르면 게임이 시작된다. 학교, 도서관 공사장, 소방서, 대피소 장면에서 회색 물건을 문지르면 색이 돌아오고 ‘가상 상황’ 카드와 세 가지 도착 방법이 나온다. 한 번은 틀리고 힌트를 본다. | 규칙이 한눈에 들어온다. 정책 이름이 나온다. |
| 반전 | 0:37~0:50 | 마지막 마을에서는 문질러도 색이 곧 빠진다. 점선이 가리키는 닫힌 창고를 문지르면 셔터가 열리고 안에 비철금속이 쌓여 있다. 마을 전체에 색이 번진다. | 지금까지의 방식이 통하지 않다가 ‘미리 쌓아 둔 것’이 답이 된다. |
| 회수 | 0:50~0:57 | 처음의 가로등과 나무에도 색이 돌아온다. 같은 구도. | 첫 장면의 질문이 답을 얻었다. |
| 한마디 | 0:57~1:00 | “오늘 하루도, 미리 도착해 있었습니다.” 위에 작품명 카드. | 이 작품은 이 한 줄이다. |

## 2. 촬영 준비

1. PC 모니터 **1920×1080**. 크롬 또는 엣지에서 `index.html`을 연다. 북마크 줄과 알림이 안 보이게 별도 브라우저 프로필을 쓰고, **F11 전체 화면**으로 둔다. 1920×1080에서 게임 화면은 가로 약 1300 픽셀로 커지고 위아래가 가운데 정렬된다(이 해상도에서 배치를 확인했다).
2. 녹화: OBS(화면 캡처 + 데스크톱 소리 캡처 켜기) 또는 Windows 게임 바(Win+G). 출력 MP4(H.264) 1920×1080, 30fps 또는 60fps.
3. 마우스 커서가 보이게 한다(OBS ‘커서 캡처’ 켜기). 게임 안에서도 문지르는 위치에 노란 빛이 따라온다.
4. **녹화를 먼저 시작하고 F5로 새로고침한다.** 새로고침 후 3초 동안 마우스를 만지지 않는다. 오프닝의 자동 문지르기(약 0.4~2.3초)가 첫 3초가 된다.
5. 소리는 첫 클릭 이후부터 난다(브라우저 정책). 오프닝 3초는 무음이어도 된다.
6. 연습을 서너 번 한 뒤 가장 매끄러운 한 판을 쓴다. **한 판을 끊지 않고 끝까지** 하고, 편집에서 줄인다.

## 3. 장면별 대본 (총 60초, 한 판의 편집본)

자막은 화면 아래 중앙, 흰 글씨와 검은 외곽선, 1080p 기준 글자 높이 약 44픽셀. 게임이 이미 화면에 띄우는 문구(질문, 하단 안내줄, 상황 카드)는 자막으로 다시 쓰지 않는다.

| 시간 | 화면·조작 | 소리 | 편집기 자막 |
|---|---|---|---|
| 0:00~0:03 | 새로고침 직후. 손 떼기. 질문과 자동 문지르기를 그대로 보여 준다. | 없음 | 없음 |
| 0:03~0:07 | 마우스로 가로등을 쓱쓱 문지른다. 색이 돌아오면 게임이 시작된다(약 1초 뒤). | 맑은 차임 | 없음 |
| 0:07~0:19 | 1장면 학교. 책상, 칠판, 시계를 각각 서너 번 문지른다(약 6초). 상황 카드가 뜨면 ‘나라장터 입찰’을 일부러 눌러 힌트를 1.5초 보이고, ‘종합쇼핑몰 주문’을 눌러 ✔와 실제 제도 설명을 1.5초 보인다. | 클릭, 도장 | 없음 |
| 0:19~0:25 | 2장면 도서관 공사. 대기 시간을 자르고 문지르기 3초, 정답 ‘나라장터 입찰’ 1초, 설명 1초. | 차임 | 종합쇼핑몰 · 나라장터 입찰 |
| 0:25~0:31 | 3장면 소방서. 같은 방식. 정답 ‘혁신제품 시범구매’. | 차임 | 혁신제품 시범구매 |
| 0:31~0:37 | 4장면 대피소. 같은 방식. 정답 ‘긴급 조달 조치’. | 차임 | 긴급 조달 조치 |
| 0:37~0:50 | 5장면 공장 마을. 공장, 전선 릴, 파이프를 한 번씩 문지르면 색이 오르다 빠진다(약 3초). 하단에 ‘왼쪽 창고를 문질러 보세요’가 뜨고 점선이 창고를 감싼다. 창고를 문지르면 셔터가 올라가고 비철금속이 보이며(약 2초), 마을 전체에 색이 번진다(약 2초). 설명 카드를 1.5초 보인다. | 낮은 울림, 차임 연속 | 없음(게임 자막 사용) |
| 0:50~0:57 | ‘결과 보기’ 클릭. 색이 돌아온 처음의 동네, 큰 문장, 도착표 다섯 줄. 커서를 ‘도착표 카드 저장’ 위에 올려 둔다(누르지 않는다). | 차임 | 없음 |
| 0:57~1:00 | 화면 그대로 두고 아래 카드 | 없음 | 미리도착한하루 · AI 게임 부문 |

(편집 후 길이 58~62초. 65초를 넘기지 않는다.)

## 4. 편집 지시

- 길이는 58~62초. 대기 시간(클릭 사이 1초 이상의 공백)과 읽기 시간 이상으로 머무는 부분을 잘라 낸다. 장면 안에서 점프 컷이 보여도 좋다.
- 확대 효과나 속도 조절을 쓰지 않는다. 장면 전환은 컷 또는 0.2초 디졸브.
- 소리는 게임 소리만 쓴다. 음악을 넣지 않는다. 평균 -14 LUFS 안팎으로 맞춘다.
- 자막 글꼴은 **상업 이용 허용을 직접 확인한 것**만 쓴다(이 문서에서는 특정 글꼴의 라이선스를 확인하지 않았다).
- 출력: MP4(H.264), 1920×1080, 비트레이트 2.5~3Mbps. 게임 화면은 단색 면이 많아 낮은 비트레이트에서도 화질이 유지된다. 이 정도면 60초에 약 20MB다. 이메일 첨부 용량 상한은 요강에 없어 02 문서 1번으로 사무국에 묻고, 한도가 작으면 비트레이트를 더 낮춘다.
- 출력 후 확인: 길이, 해상도 1920×1080(파일 속성), 소리가 들리는지, 자막 오타, 파일명.

ffmpeg가 있으면 용량 줄이기 예(편집기 출력 설정으로도 같다):

```
ffmpeg -i 원본.mp4 -c:v libx264 -b:v 2500k -maxrate 3000k -bufsize 6000k -vf scale=1920:1080 -c:a aac -b:a 128k -movflags +faststart AI게임_시연영상_미리도착한하루_성명.mp4
```

## 5. 촬영이 잘 안 풀릴 때

| 문제 | 해결 |
|---|---|
| 첫 3초에 자동 문지르기가 안 보인다 | 새로고침 후 마우스를 건드렸다. 3초 동안 손을 떼고 다시 찍는다. |
| 5장면에서 힌트(점선)가 안 뜬다 | 공장, 전선 릴, 파이프를 한 번씩 더 문지르거나 9초를 기다린다. |
| 소리가 녹음되지 않는다 | OBS ‘데스크톱 오디오’와 브라우저 탭 음소거를 확인한다. 우상단 버튼이 ‘소리 켜짐’이어야 한다. 소리가 없어도 자막만으로 성립한다. |
| 화면이 작게 나온다 | F11 전체 화면, 모니터 1920×1080인지 확인한다. 해상도가 낮으면 1080p 미만이 되어 규격 위반이다. |
| 60초를 넘는다 | 2~4장면의 문지르기 구간을 더 줄인다. 0:00~0:07(오프닝), 5장면, 엔딩은 줄이지 않는다. |
